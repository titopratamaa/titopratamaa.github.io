# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## Personal Portfolio Website – Tito Pratama Kurnala Dewa

### 1. Product Overview

**Nama Produk:** Personal Portfolio Website – Tito Pratama Kurnala Dewa

**Jenis Produk:** Personal CV & Portfolio Website

**Platform:** Web Responsive (Desktop, Tablet, Mobile)

**Target Pengguna:**

* Recruiter / HRD perusahaan energi dan migas
* Hiring manager
* Profesional di bidang oil & gas
* Perusahaan yang membutuhkan kandidat untuk posisi Field, Operation, Reservoir, atau Production Support

**Tujuan Website:**
Menyediakan profil profesional online yang menampilkan latar belakang pendidikan, pengalaman magang, kemampuan teknis, sertifikasi, dan informasi kontak sehingga recruiter dapat memahami profil kandidat dengan cepat.

---

# 2. Background

Tito Pratama Kurnala Dewa merupakan lulusan S1 Teknik Perminyakan Universitas Proklamasi 45 Yogyakarta dengan IPK 3.05/4.00.

Memiliki pengalaman magang pada bidang **Reservoir & Production** melalui program IATMI selama Januari 2023 – Juli 2024. Pengalaman tersebut mencakup pengolahan data reservoir dan produksi menggunakan IPM-MBAL, evaluasi kinerja lapangan, penentuan mekanisme pendorong, estimasi OOIP, serta penyusunan laporan teknis.

Website dibuat sebagai versi digital dari CV agar informasi kandidat dapat disajikan secara lebih terstruktur dan mudah diakses.

---

# 3. Product Goals

Website harus mampu:

1. Menampilkan profil kandidat secara profesional.
2. Menjelaskan latar belakang pendidikan Teknik Perminyakan.
3. Menampilkan pengalaman magang dan tanggung jawab teknis.
4. Menampilkan technical skills dan core skills.
5. Menampilkan sertifikasi dan training.
6. Menampilkan tugas akhir sebagai salah satu project utama.
7. Menyediakan kontak yang mudah ditemukan recruiter.
8. Memiliki tampilan responsive pada desktop dan mobile.
9. Memiliki navigasi sederhana sehingga recruiter dapat menemukan informasi penting dengan cepat.

# 15. Non-Functional Requirements

### Performance

* Website ringan.
* Target loading cepat.
* Optimasi gambar.
* Hindari animasi berat.

### Responsive

Website harus berjalan dengan baik pada:

* Desktop
* Laptop
* Tablet
* Mobile

### Accessibility

* Kontras teks mudah dibaca.
* Button memiliki label yang jelas.
* Struktur heading menggunakan hierarchy yang benar.
* Semua gambar memiliki alt text.

### Security

* Tidak menyimpan data sensitif pengguna.
* Contact form, jika digunakan, harus memiliki validasi.
* Tidak menampilkan informasi pribadi selain informasi yang memang diperlukan untuk kebutuhan profesional.
